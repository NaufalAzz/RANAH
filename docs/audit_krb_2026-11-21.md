# Audit lokasi dan referensi KRB — 21 November 2026

## Hasil

- 69 koordinat referensi diperiksa ulang terhadap daftar marker pada https://magma.esdm.go.id/ dan tidak berubah.
- Kekosongan penanda laporan sebelumnya disebabkan gerbang validasi koordinat database yang masih menolak referensi MAGMA independen. Gerbang tersebut diperbaiki; nama asing tetap membutuhkan koordinat database yang terverifikasi.
- Klik ikon peta utama mencocokkan nama/alias secara utuh dengan ID dari API RANAH. Tidak memakai tebakan ID atau pencocokan substring.
- Overlay BIG yang terverifikasi tetap 27 gunung (151 fitur).
- Ditambahkan 40 dokumen peta KRB MAGMA untuk gunung tanpa overlay. Dokumen dapat dilihat dan diperbesar di dalam aplikasi; memerlukan internet dan tidak ditempel sebagai overlay tanpa georeferensi.
- Cakupan referensi KRB menjadi 67 dari 69 gunung: 27 overlay + 40 dokumen. Hobal dan Lamongan belum memperoleh tambahan KRB yang cocok dari katalog yang diperiksa.

## Sumber dan batasan

- [Koordinat MAGMA / PVMBG](https://magma.esdm.go.id/).
- [Katalog peta KRB resmi MAGMA](https://magma.esdm.go.id/v1/gunung-api/peta-kawasan-rawan-bencana). Nama dicocokkan tepat setelah normalisasi; entri uji unggah tidak digunakan.
- [Layer poligon BIG](https://kspservices.big.go.id/satupeta/rest/services/PUBLIK/SUMBER_DAYA_ALAM_DAN_LINGKUNGAN/MapServer/11). Metadata sumber dapat diperiksa, tetapi unduhan geometri dari executor ditolak proxy HTTP 403. Tidak menandai 41 kandidat lama sebagai terverifikasi tanpa memeriksa geometrinya.
- 40 URL gambar diperiksa dengan HTTP GET pada 21 November 2026: seluruhnya HTTP 200, bertipe JPEG dan memiliki signature JPEG. Contoh berkas peta juga diperiksa secara visual.
- Tahun dokumen ditampilkan sesuai katalog, bukan dianggap peta terbaru. Tahun sumber overlay BIG lama tetap dipertahankan. Tidak mengubah database atau menggambar zona bahaya buatan.
